🗂️ Categorías y subcategorías
¿Cómo funciona?
  1. Cada ensayo vive dentro de una subcategoría, y cada subcategoría dentro de una categoría.
  2. Al crear una categoría se crea sola la subcategoría General, para que puedas agregar ensayos de inmediato.
  3. Lo que ya tiene ensayos no se borra, se desactiva: deja de salir en Nueva Cotización, pero tus cotizaciones y el Dashboard conservan su historial.
  4. El prefijo (ej. SU) arma el código de los ensayos (SU-01) y queda fijo cuando la categoría ya tiene ensayos.
  5. Un paquete se arma con ensayos reales del catálogo (mínimo 2, pueden ser de otra categoría). No se meten paquetes dentro de paquetes, y si corriges un ensayo, sus paquetes lo ven actualizado.

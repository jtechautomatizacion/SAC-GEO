# 🎯 ESTRATEGIA DE VENTA CONSULTIVA PARA PWA PRESUPUESTOS
## Cómo Vender Primero con Preguntas y Luego Enamorar con la Propuesta

---

## FASE 1: DESCUBRIMIENTO (15-20 minutos)
### "Preguntas que hacen pensar"
**Objetivo:** Entender el dolor real, no solo vender una solución

### Preguntas de Apertura (Que se sienta escuchado)
```
"GTQC es una empresa de consultoría de calidad. Cuéntame...

1. ¿Cuál es tu proceso actual para generar presupuestos?
   └─ Escucha: Problemas reales (tiempo, errores, desorden)

2. ¿Cuántos presupuestos generan al mes?
   └─ Escucha: Volumen = oportunidad de ahorro

3. ¿Qué pasa cuando un presupuesto se pierde o se modifica?
   └─ Escucha: DOLOR LEGAL/FINANCIERO

4. ¿Cómo controlan actualmente quién cambió qué en un presupuesto?
   └─ Escucha: Falta de trazabilidad = compliance risk

5. ¿Dónde guardan los PDFs generados? ¿Todos tienen acceso?
   └─ Escucha: Desorganización + falta de seguridad
```

### Preguntas Sobre Sus Herramientas Actuales
```
6. ¿Usan Microsoft 365? ¿Tienen Teams, OneDrive?
   └─ Escucha: Tecnología que ya tienen (reduce fricción)

7. ¿Qué necesitarían para que un presupuesto fuera "oficial"?
   └─ Escucha: Qué significa legitimidad para ellos

8. Si pudieran mejorar UNA cosa del proceso, ¿cuál sería?
   └─ Escucha: PRIORIDAD REAL
```

### Preguntas Sobre Expectativas y Decisión
```
9. ¿Cuándo necesitarían una solución como esta?
   └─ Escucha: Timeline, urgencia

10. ¿Quién más estaría involucrado en esta decisión?
    └─ Escucha: Identificar stakeholders (finanzas, legal, IT)
```

---

## FASE 2: VALIDACIÓN (Lo que dijeron es real)
### "Repite lo que escuchaste para generar confianza"

**TÚ:** "Si entiendo bien, ustedes..."
- Generan X presupuestos al mes
- Hoy se guardan en [donde] y no hay control de acceso
- Cuando se modifica un presupuesto, [no hay log/no sabes quién lo hizo]
- Necesitarían que esto se resolviera antes de [fecha]

**CLIENTE:** Asiente o corrige

**TÚ:** "Perfecto. Creo que tengo una solución que resuelve exactamente esto."

## FASE 3: ENAMORAMIENTO (La Propuesta Mágica)
### "Muestra la visión, no la tecnología"

**NO HAGAS ESTO:** "Voy a usar Node.js con IndexedDB y PWA con Service Workers..."
**HACES ESTO:** Muestra lo que SIENTE usar la solución

### El Viaje Emocional (6 pasos)

#### PASO 1: El Problema (Dolor)
```
"Hoy, un ejecutivo en obra genera un presupuesto, 
lo guarda en email o en una carpeta compartida.
Después, otro colega lo modifica sin que nadie sepa.
El cliente recibe dos presupuestos diferentes y desconfía.
Además, si hay una auditoría, no tienes prueba de quién cambió qué."
```

#### PASO 2: El Frustración (Por qué no se resuelve)
```
"Lo intentas con Excel → Errores, lentitud, sincronización complicada
Lo intentas con software caro → Implementación de 3 meses, capacitación compleja
Lo intentas con papelería → No escalable, fácil de perder"
```

#### PASO 3: La Idea (La Solución Simple)
```
"¿Y si...todo este proceso fuera AUTOMÁTICO?

- El ejecutivo llena un formulario en su celular (con o sin internet)
- La PWA calcula automáticamente el total, IGV, descuentos
- Genera un PDF con QR inviolable
- Se guarda automáticamente en OneDrive de GTQC
- Todo quedan registrado: quién, cuándo, qué cambió"
```

#### PASO 4: El Momento "Wow" (Muestra el Mockup)
**Abre la pantalla interactiva HTML y di:**

```
"Mira esto.

[PANTALLA 1 - Crear Presupuesto]
El ejecutor abre esto en su celular, incluso sin internet.
Ingresa el RUC del cliente → el sistema trae automáticamente 
nombre legal, dirección, desde SUNAT. Cero errores.

[PANTALLA 2 - Agregar Servicios]
Aquí elige entre servicios por PAQUETE o por UNIDAD.
Puede mezclar los dos. El cálculo es instantáneo.

[PANTALLA 3 - Calcular Totales]
Aquí ve el total, puede aplicar descuentos, configurar IGV.
Si le parece, genera el PDF.

[PANTALLA 4 - Generación de PDF]
Dos opciones:
  - PDF Rápido (< 1 segundo, offline, jsPDF)
  - PDF Oficial (2-3 segundos, digitalmente firmado, servidor)

[PANTALLA 5 - Envío]
El cliente recibe email con botón para escanear QR.
Si alguien intenta modificar el PDF después... imposible.
El QR lo detectaría."
```

#### PASO 5: Los Beneficios (Por qué debería importarle)
```
✓ SEGURIDAD
  → Presupuestos imposibles de falsificar
  → Cliente confía en GTQC (diferenciación vs competencia)

✓ TRAZABILIDAD
  → Auditoría completa: quién, cuándo, qué cambió
  → Si hay disputa: tienes prueba de todo
  → Cumples normativa peruana de documentos tributarios

✓ ORGANIZACIÓN
  → Todos los PDFs automáticamente en OneDrive de GTQC
  → Acceso desde cualquier dispositivo, cualquier hora
  → Buscable, versionado, compartible de forma segura

✓ TIEMPO
  → Sin validaciones manuales → menos errores
  → Sin correos "¿dónde está el presupuesto?" → menos ruido
  → Genera PDF en < 3 segundos

✓ INTEGRACIÓN
  → Ya tienen Microsoft 365 → cero implementación extra
  → Funciona offline → ejecutivos en obra sin WiFi
  → PWA significa sin descarga, sin instalación
```

#### PASO 6: El Cierre Emocional (La Visión)
```
"Imagina que tu equipo tiene el mejor proceso de presupuestos 
en toda la industria. Los clientes reciben PDFs profesionales, 
pueden verificar autenticidad con un QR. 

GTQC aparece como una empresa moderna, segura, organizada.

Mientras tus competidores sigue usando Excel y email,
tú tienes automación, trazabilidad, profesionalismo.

Eso se vende. Eso genera confianza.
Eso te diferencia."
```

## FASE 4: MANEJO DE OBJECIONES
### "Anticipa las objeciones y cierralas con elegancia"

#### OBJECIÓN 1: "¿Cuánto cuesta?"
**NO DIGAS:** "Depende de la complejidad..."
**DI:** 
```
"Excelente pregunta. Primero, déjame preguntar:
- ¿Cuántas horas/mes pierden en gestionar presupuestos?
- ¿Cuántos errores/año cuestan plata/reputación?

Si recuperamos solo 20 horas/mes de tu equipo,
ya está pagado. Además, el riesgo legal de no tener auditoría...
¿cuánto vale eso?

Pero primero vamos a validar si esta solución 
es lo que necesitan. ¿De acuerdo?"
```

#### OBJECIÓN 2: "Parece complicado de implementar"
**NO DIGAS:** "No, es fácil..."
**DI:**
```
"Entiendo la preocupación. Pero mira:

- Es una PWA: sin instalación. Solo un link en el celular.
- Funciona con tus herramientas actuales (365, Teams)
- En 1 semana está en producción
- Yo estaré aquí para capacitar a tu equipo

Y si después de 2 semanas no te convence,
sin problema. Pero créeme, te va a enamorar."
```

#### OBJECIÓN 3: "¿Qué pasa si se cae el servidor?"
**NO DIGAS:** "Eso casi nunca pasa..."
**DI:**
```
"Muy buena observación, eso muestra que te importa la continuidad.

La PWA funciona OFFLINE. Si no hay internet:
- El ejecutor sigue rellenando presupuestos
- Se guardan localmente en su celular
- Cuando vuelve la conexión, se sincronizan automáticamente
- Cero datos perdidos

Además, los servidores están en Azure (Microsoft),
con SLA del 99.9% y backup automático."
```

#### OBJECIÓN 4: "Nuestro sistema actual funciona..."
**NO DIGAS:** "Pero es ineficiente..."
**DI:**
```
"Claro, por eso sigues en el negocio. Probablemente funciona.

Pero piensa en esto: ¿cuánto POTENCIAL estás dejando?
¿Cuántos clientes potenciales pierdes porque tu proceso
se ve "artesanal" comparado con competidores tech?

No se trata de reemplazar lo que funciona.
Se trata de evolucionar lo que PODRÍA funcionar mejor.

¿Estarías abierto a una prueba piloto con 5 presupuestos
para que veas la diferencia?"
```

## FASE 5: EL CIERRE
### "3 formas de cerrar sin ser agresivo"

#### CIERRE 1: Assumptive Close (Asume el "sí")
```
"Perfecto. Entonces el siguiente paso es:
- Yo presento esto a tu equipo en una reunión corta (30 min)
- Hacemos una prueba piloto con 5 presupuestos esta semana
- Vemos cómo reacciona tu equipo

¿Te va bien mañana a las 3pm o el jueves a las 10am?"
```

#### CIERRE 2: Choice Close (Dale opciones)
```
"Entiendo que quieras pensarlo. Pero sé que te interesa
porque hiciste buenas preguntas.

¿Prefieres que:
a) Te mande un email con demo acceso para que pruebes solo?
b) Hacemos una sesión de 30min con tu equipo esta semana?
c) Ambas cosas?"
```

#### CIERRE 3: Risk Reversal (Elimina el riesgo)
```
"Mira, sé que cambiar procesos genera incertidumbre.

Por eso te propongo esto:
- Implementamos el sistema esta semana
- Lo usamos en paralelo con tu proceso actual (sin riesgos)
- Si después de 2 semanas no ves valor, cancelamos todo
- Cero compromiso, cero costo, cero problema

¿Podemos intentarlo?"
```

📊 Resumen Rápido de Tablas

11 TABLAS Total de entidades
3 MAESTRAS EMPRESAS, PERSONAS, ENSAYOS
1 CENTRAL COTIZACIONES (eje del sistema)
7 DETALLES Items, descuentos, envíos, etc.

🔄 Flujos Principales de Datos

1️⃣ CREAR COTIZACIÓN
Cliente (EMPRESAS/PERSONAS) → Plantilla (PLANTILLAS) → Cotización (COTIZACIONES)
2️⃣ AGREGAR ITEMS
Ensayo/Paquete (CATALOGO) → Item (COTIZACION_ITEMS) → Cotización
3️⃣ APLICAR DESCUENTOS
Descuento → (DESCUENTOS) → Recalcula TOTAL en COTIZACIONES
4️⃣ DESCARGAR/ENVIAR
Cotización → PDF (COTIZACION_DESCARGAS) O Email/WhatsApp (COTIZACION_ENVIOS)

🔗 Relaciones Entre Tablas

1:N EMPRESAS → CONTACTOS (Una empresa tiene muchos contactos)
N:N PAQUETES → ENSAYOS (Un paquete tiene múltiples ensayos)
1:N COTIZACIONES → COTIZACION_ITEMS (Una coti tiene muchos items)
1:N COTIZACIONES → DESCUENTOS (Una coti puede tener descuentos)
1:N COTIZACIONES → COTIZACION_DESCARGAS (Registra descargas)
1:N COTIZACIONES → COTIZACION_ENVIOS (Registra envíos)
1:N PLANTILLAS → COTIZACIONES (Una plantilla en muchas cotas)

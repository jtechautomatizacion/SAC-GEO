```
❌ "Usa Node.js, Service Workers, IndexedDB..."
✅ "El ejecutor en obra, sin internet, genera presupuesto en 3 segundos"
```

### ERROR 2: No escuchar
```
❌ Hablar 70%, escuchar 30%
✅ Hablar 30%, escuchar 70%
```

### ERROR 3: No validar lo escuchado
```
❌ Cliente dice algo, tú ignoras y sigues
✅ "Si entiendo bien, el problema es X. ¿Correcto?"
```

### ERROR 4: No mostrar el mockup
```
❌ Describir verbalmente cómo funciona
✅ Abrir la pantalla y que lo VEA en tiempo real
```

### ERROR 5: Presionar demasiado
```
❌ "¿Firmas hoy?"
✅ "¿Hacemos una prueba piloto?"
```

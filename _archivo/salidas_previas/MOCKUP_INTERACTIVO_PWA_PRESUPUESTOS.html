📦 Sistema de Paquetes vs Unidades (FLEXIBLE)

📦 POR PAQUETES (Tarifa Cerrada)

  • ✓ Precio fijo por servicio completo
  • ✓ No se especifican unidades
  • ✓ Ejemplo: "Estudio Completo = S/ 3,500"
  • ✓ Mejor para servicios integrales
  • ✓ Tiempo estimado incluido
  • ✓ Campo: "Cantidad" = 1

📏 POR UNIDADES (Tarifa Variable)

  • ✓ Precio por unidad específica
  • ✓ Cantidad variable según cliente
  • ✓ Ejemplo: "S/ 70 por ensayo x 4 = S/ 280"
  • ✓ Mejor para servicios parciales
  • ✓ Flexible según necesidad
  • ✓ Campo: "Cantidad" editable

💡 ¿Cómo Funciona en la PWA?

La PWA es completamente flexible. En cada servicio, GTQC puede definir si se vende:

  • • PAQUETE: Campo "Cantidad" deshabilitado (siempre 1) → Precio unitario = Precio paquete
  • • UNIDAD: Campo "Cantidad" habilitado (usuario ingresa cantidad) → Subtotal = Cantidad × Precio unitario
  • • HÍBRIDO: Algunos servicios por paquete, otros por unidad en el mismo presupuesto

    ✨ Características Clave de la PWA

    ✅ Validación SUNAT Automática

    Cuando el usuario ingresa un RUC, la PWA lo valida en tiempo real contra el padrón de SUNAT. Si es válido, se completan automáticamente: Razón Social, Dirección, Teléfono, etc.

    📱 Funciona Offline

    Los ejecutivos pueden crear presupuestos sin internet. Cuando se reconecta, la PWA sincroniza automáticamente todos los cambios. Perfecto para trabajos en campo.

    ⚡ Generación PDF Dual

    Dos opciones: PDF rápido en navegador (<1 seg, sin internet) o PDF profesional en servidor (con firma digital y código QR).

    🎯 Sistema Flexible (Paquetes o Unidades)

    Cada servicio se puede vender como paquete (tarifa cerrada) o por unidad (cantidad variable). O mezclar ambas en el mismo presupuesto.

    📊 Cálculos Automáticos

    Subtotales, descuentos, IGV: todo se calcula en tiempo real mientras escribes. Sin errores manuales.

    📧 Envío Directo

    Genera el presupuesto y envíalo directamente por email al cliente. El PDF se adjunta automáticamente.

    📜 Sección de Términos y Condiciones

    Nota: Esta sección es editable en cada presupuesto o puede tener un template por defecto.

    Cómo Funciona en la PWA:

    • ✓ Template Predefinido: Sistema carga términos estándar para todos los presupuestos
    • ✓ Editable por Presupuesto: Ejecutivo puede personalizar términos para clientes especiales
    • ✓ Historial: Se guarda versión de términos usados en cada presupuesto
    • ✓ En PDF: Los términos aparecen automáticamente al pie del presupuesto generado

    🔧 Configuración de Servicios: Paquetes vs Unidades

    📦 CONFIGURACIÓN PAQUETE

    Caso Actual GTQC: "ESTUDIO DE SUELOS"

    En la PWA:

    • Nombre: "Estudio Completo Suelos"

    • Tipo: PAQUETE ☑️

    • Precio: S/ 3,500 (tarifa cerrada)

    • Cantidad: 1 (deshabilitada para editar)

    • Subtotal: S/ 3,500 (siempre)

    Usuario no puede cambiar: La cantidad siempre será 1. El cliente paga la tarifa cerrada completa.

    📏 CONFIGURACIÓN UNIDAD

    Caso Actual GTQC: "ENSAYO TRIAXIAL"

    En la PWA:

    • Nombre: "Ensayo Triaxial"

    • Tipo: UNIDAD ☑️

    • Precio Unitario: S/ 650

    • Cantidad: (editable)

    • Subtotal: S/ 1,300 (2 × 650)

    Usuario sí puede cambiar: La cantidad es flexible. Si cliente necesita 5 ensayos: 5 × S/ 650 = S/ 3,250.
